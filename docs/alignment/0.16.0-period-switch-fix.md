# 0.16.0 补充修复：sample 周期数据

日期：2026-11-03。本轮只修改 sample 数据源、相关验证与说明，图表库结构、API 和上游 v10.1.0 基线保持。

## 问题与验收条件

原 LocalFeed 在每次 INIT 重置相同随机种子及价格，五个周期得到逐根相同的 500 组 OHLCV，只改变时间戳。旧周期测试仅验证时间间隔，未验证价格语义。修复前新增的 `periodsAggregateSameMarketRatherThanRetimestampingPrices` 已在设备上失败（5m 与 1m 价格相同）。

本次必须满足：

1. 1m/5m/15m/1h/1d 共用同一标的的基础分钟行情，以 UTC 固定桶聚合 OHLCV，不能靠修改随机种子让图形看起来不同。
2. 开盘取首、收盘取末、最高取最大、最低取最小、成交量求和；完整桶、未完成末桶与历史页保持一致。
3. 保留初始 500 根、最多三页历史（每页 200 根）、暂停/退订及替换末根的高低价单调性；切周期沿用模拟时钟。
4. 所有周期共用每秒推进一分钟的模拟时间；200ms 一次更新，每五次更新完成一根分钟 K 线，较大周期只在其时间边界追加新根。
5. 日线批量计算在后台完成，按桶检查取消，不存储百万根分钟对象；压力模式继续使用原有生成路径。
6. 验证真实按钮的数据变化；最终 R8 页面暂停推送后，只比较主图内部像素，排除按钮、图例和时间标签变化造成的假通过。

## 实现与边界

LocalFeed 以时间、种子和标的生成可重复的分钟价格/高低价/成交量，逐桶流式聚合；同一时间点、标的和种子对应同一份基础数据。当前分钟按五个阶段更新，最后阶段与历史完整分钟完全一致。没有添加缓存、依赖或新的模块。

这是本地加速模拟，不是交易所行情。只支持固定分钟至 24 小时桶；交易日历、节假日和交易所日线开盘时区不在 sample 本轮范围。

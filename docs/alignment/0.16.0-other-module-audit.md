### 兼容性说明

- 时间查询由 floor 改为最近邻；非精确时间的普通点锚点和定位结果可能移动到后一根。这里只修复已加载数据的查询约定，没有新增基于 Period 推算尚未加载 candle 的整套 API。
- 创建中 `points` 含临时预览末点，`currentStep` 仍计已确认点；完成与存档不会额外增加预览点。旧 brush 存档已丢失的槽内精度无法自动恢复。
- 默认 tooltip 偏移现为上游的 left/right=4、top/bottom=6。副图显示名称、参数与图形标题，空间不足时继续换行；极小 pane / 超大字号的物理空间限制仍存在，放不下的后续图例行可能被省略（例如字体 2.0 下的 VOL 尾项），不据此宣称所有图例始终完整可见。
- 高低点价格文字改用自身数字布局测量，并在横纵方向都受阻时搜索空闲角落；极矮 pane 找不到完整文字空位时省略该可选标注，避免覆盖指标图例。普通布局仍验证高、低标注均可见。
- rect 本身按上游是可覆盖绘图区的卡片；此前“名称和数值被曲线穿过”的 standard 图例继续保留 Android 最小留白。两者不使用同一避让高度。

## 本轮排查中一并关闭的必修关联项

- 历史视口中的 MA 超出 candle 高低范围：原本只扫描 candle，例为前 60 根 close=1000、之后 close=100，MA60[60]=985，原投影严重越界。本版将可见默认轴指标图列纳入共享范围；独立轴保持独立范围；指标建删/参数/可见性变化使缓存失效。
- 同末根 candle 激活/关闭十字线时，tooltip 缓存遗漏激活状态；rect 模式同 candle 内移动遗漏坐标。本版补充缓存键与原生像素对照。
- snapped Float x 转回索引可能为 927.999999978326 而误选 927。本版十字线消费者统一最近索引，新增小数间距回归。
- 新增十字线保持后，重复短按的 candle 点击回调、feature 输入优先级、市场/周期 RESET 清除选择均纳入本版。
- 导出不能覆盖屏幕测得的图例几何；本版 finally 恢复图例高度与 feature 命中区，新增导出前后坐标一致性验证。

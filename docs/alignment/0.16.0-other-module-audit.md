## 本轮排查中一并关闭的必修关联项

- 历史视口中的 MA 超出 candle 高低范围：原本只扫描 candle，例为前 60 根 close=1000、之后 close=100，MA60[60]=985，原投影严重越界。本版将可见默认轴指标图列纳入共享范围；独立轴保持独立范围；指标建删/参数/可见性变化使缓存失效。
- 同末根 candle 激活/关闭十字线时，tooltip 缓存遗漏激活状态；rect 模式同 candle 内移动遗漏坐标。本版补充缓存键与原生像素对照。
- snapped Float x 转回索引可能为 927.999999978326 而误选 927。本版十字线消费者统一最近索引，新增小数间距回归。
- 新增十字线保持后，重复短按的 candle 点击回调、feature 输入优先级、市场/周期 RESET 清除选择均纳入本版。
- 导出不能覆盖屏幕测得的图例几何；本版 finally 恢复图例高度与 feature 命中区，新增导出前后坐标一致性验证。

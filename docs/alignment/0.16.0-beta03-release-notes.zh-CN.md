## 右轴自适应轴宽（R11-01）

- **根因**：右轴槽宽为纯配置常量（`ChartLayoutConfig.rightAxisGutter`），刻度/tag
  文本从不参与槽宽计算；槽过窄时越界仅画布硬裁切。上游 `yAxis.size` 默认值即
  `'auto'`（`common/Styles.ts:663`），LKanvas 固定 gutter 属对齐缺口。
- **修复**：新增 `draw/AxisWidthPolicy.kt`——上游 `component/YAxis.ts`
  `getAutoSize`/`_settleWidth`/`widthAnchorValue` 的平台层移植（structure-map §4）：
  - 槽宽 = max(配置 gutter 下限, 实测全部 gutter 内文本所需宽度)；
  - 实测范围：主图 `YAxisMath` 刻度 + vol/macd/动态副图 `LinearYAxis` 刻度 +
    末价/十字线 tag（tag 最坏文本按主区当前量级十位锚点估算）；
  - 防抖与上游一致：立即扩宽（标签必须放得下）、静默 400ms 后才收窄、4px 网格取整
    （防数字噪声抖列宽，并打破「槽宽→内容宽→刻度文本→槽宽」布局回环）。
- **反馈链**：`ChartState.applyAxisGutter` 帧末回写 contentWidthPx（4px 网格阈值），
  手势 `isInAxisGutter` 轴槽命中同源；viewport 保持锚定不重置缩放。
- **导出**：PNG 导出复用屏幕生效槽宽（所见即所得），不回写、不在导出度量下重算 settle。
- **宿主影响**：`rightAxisGutter` 语义调整为槽宽**下限**（默认 64dp 不变）；
  46dp 宿主配置在大数量级数据下自动扩到实测所需，刻度单行不再截断/换行。

## 职责域澄清（issue #1 备注）

- `Formatter.formatBigNumber` 职责域维持**指标图例/tooltip**（IND-009；K/M/B 分档
  IDX-015），轴刻度维持 SLA-011 精度链——上游轴刻度文本同样不做缩写，宽度溢出由
  自适应轴宽解决，轴文本不引入缩写。上游仅 crosshair 宽度估算消费 formatBigNumber，
  本实现以主区十位锚点 `widthAnchorValue` 同等覆盖。
- `YAxisStyle.size` 样式树保持 `Double`（beta 冻结期不引入 `'auto'` 联合类型字段）；
  `'auto'` 语义为平台层默认行为，字段级对齐留待后续提案。

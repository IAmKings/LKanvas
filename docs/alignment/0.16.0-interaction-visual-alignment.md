# 0.16.0 手势与画面对齐

日期：2026-11-03。上游固定为 KLineChart v10.1.0；起点 c6968bd（0.15.1-rc5）。本文件同时作为本次修复的规格与验证记录。

## 必修范围

1. 普通短按开启十字线；长按仍可开启；松手保持。靠近已有十字线再次拖动可检查数据，远处触摸关闭；绘图、feature 和轴区保留各自输入优先级。
2. 右拖内容跟随手指，显示更早数据。惯性、scrollByDistance、定位 API 和动画使用一致的内容位移语义；边界事件报告实际距离。
3. 纵轴默认及覆写 gap 进入绘制、标签、正反坐标转换与覆盖物投影，包含主图、副图和独立轴。
4. MA/VOL/MACD 图例名称与数值保持可读，按实际字形和换行高度保护图例区域。保留上游 standard 叠加形式，Android 字体造成的空间不足采用最小图例留白适配，并明确登记该平台差异。
5. 不改变现有模块结构，不增加依赖；版本配置与独立 consumer 一致更新为 0.16.0。

## 验证要求

- 原问题必须有能失败的用例；状态方法测试不能代替真实触摸路径。
- 覆盖短按、长按、松手、再次触摸、右拖、惯性与定位；覆盖字体和横竖屏下完整图形与图例的组合。
- 运行 core/compose 回归、Android 针对性验证、制品构建及本地 consumer 验证；不覆盖冻结的 0.15.0 制品。
- 本地功能验收不自动解除历史性能与全发布矩阵的 HOLD，不执行远端发布。

## 非必修排查

深查画线创建/选择/拖动/回调/磁吸/分 pane、轴与样式消费，以及数据和扩展契约。确认项必须给出具体输入、实际行为、上游对照及最小处理方向；证据不足的项标记为待验证。初次修复阶段，除必修链路所需其余只登记；用户随后授权修复登记的 8 项，当前状态见[其他模块修复记录](0.16.0-other-module-audit.md)。

## 执行记录

- 修复前：InteractionAlignmentTest 两项 JVM 用例失败（内容右移方向、纵轴 gap）；设备真实短按用例失败（松手后没有十字线）。
- 版本已统一为 **0.16.0 / versionCode 6**，模块结构与依赖保持。
- 短按/长按松手保持、近处续拖、远处关闭；重复短按回调、feature 优先级、RESET 清除和小数索引的数据一致性一并收口。
- 正内容位移显示历史；惯性/定位动画共用入口，onScroll 报告边界钳制后的实际距离。修正了历史测试中相反的方向和错误的右锚预期。
- 轴 gap 在 real 空间扩展，绘制/刻度/正反转换/覆盖物共用有效范围。图例先度量再绘制，最小留白按实际换行计算；反向轴也避让屏幕顶部。MA 值域纳入可见图列，指标变化使原始范围缓存失效。
- VOL 采用模板 shouldFormatBigNumber 与实例精度，避免大数无谓挤占；sample 副图高度随字体调整。布局默认高度更新生效，显式 pane 调整保留并继续遵守边界钳制。
- 导出 finally 恢复屏幕图例几何和 feature 命中区；缓存键包括十字线激活状态及 rect 坐标。

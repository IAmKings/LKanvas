# 0.16.0-beta02 发布记录（2026-11-04）

对应 Catnip 迁移降级项复核计划（catnip-migration-remediation-plan-2026-11-04）的
S2/S3 库修复包与 S5 制品集成。基线：KLineChart v10.1.0 快照不变、模块结构不变、
内置指标计算口径不变。

## 变更清单

1. **指标实例样式贯通绘制（S2）**
   - 新增 core 中性类型：`BarColorsContext`（有效三色 hex 上下文）、`ContextPlotStyles`
     （携带上下文的 figure.styles 提供者）。
   - 内置 VOL（收/开比较）与 MACD（值正负）柱色改从上下文读取；全局/实例均未
     配置时保持原字面量默认（默认外观不变，`OtherModuleAlignmentTest` 守护）。
   - 新增 compose 公开 API：`IndicatorStyleSpec` / `IndicatorBarColors`（styles: Any?
     的认可形态，additive）；归一化入口 `IndicatorStyleResolver`（IndicatorStyleSpec /
     IndicatorStyle / 旧 List<PolygonStyle> 三形态；未知形态静默忽略）。
   - 解析顺序 = 全局 styles（indicator.bars 显式配置，经 ChartTheme.barColorsContext
     桥接）→ 实例覆盖 → figure 动态（provider 消费合并结果）。绘制与 legend/tooltip
     共用同一解析（legend 色恒等于图形色）。
   - legend 缓存 key 加入实例 styles 身份（override 即失效重绘）。
2. **日期 formatter 接入真实绘制（S3）**
   - 公开 `Formatter.formatDate(ts, template, type)` 三参契约保持；库在真实消费点
     传入场景 `xAxis` / `tooltip`（`crosshair` 常量已备，本轮无 crosshair 日期浮签）。
   - 模板 token：`HH:mm` / `MM-dd` / `yy/MM-dd`（`ChartState.TEMPLATE_*`，与默认
     标签同一分支规则产出，formatter 未配置点回退默认路径与既有标签缓存）。
   - 消费点：时间轴（xAxis）、tooltip 标题时间、无障碍语义、legendData 默认时间。
   - 修复 legendData 默认时间不消费有效时区（此前跟随设备时区漂移）。
   - `setFormatter`/分隔/折叠变更 → `notifyFormatChanged()` 重绘 + tooltip 缓存 key
     加 formatConfig 身份。
3. **附带**：跨构建脚本无变化；`app-sample` 版本号同步 beta02；对齐矩阵
   IND-014/017/CH-019/020 → 行为通过（含 JVM 与设备端测试引用）。

## 兼容性登记（beta01 → beta02）

| 项 | 类型 | 说明 |
|---|---|---|
| `ChartState.FormatConfig` | 嵌套 data class 新增末尾默认参数 `formatDateByScene` | **源码兼容**（命名/默认参数调用不受影响）；**构造器 JVM 签名变化**——直接以位置参数构造 FormatConfig 的已编译调用方需重编（预计无外部调用方；该配置由门面内部同步） |
| `ChartTheme` | 新增末尾默认参数 `barColorsContext` | 同上：源码兼容、构造器签名变化；建议具名/默认构造的调用方不受影响 |
| `PaneRenderers.styleOverrideFor` / `figureColors` | **internal** 对象方法加参 | 模块内符号，非公开 ABI |
| 新公开类型 | 纯新增 | `IndicatorStyleSpec`、`IndicatorBarColors`、`BarColorsContext`、`ContextPlotStyles`、`IndicatorStyleResolver`（internal） |
| 行为变化 | VOL/MACD 柱色解析 | 全局 styles `indicator.bars` 显式配置**开始生效**（此前为死字段）；未配置外观不变 |

公开方法签名（createIndicator/overrideIndicator/setFormatter 等）零改动。

## 发布操作（人工）

1. 推送 tag：`git tag 0.16.0-beta02 && git push origin 0.16.0-beta02`
   （JitPack 通道要求 tag 与 `lkanvas.version` 完全一致，无 v 前缀；
   `v0.16.0-beta02` 可选作为附注 tag，不参与解析）。
2. JitPack 构建完成后（`https://jitpack.io/com/github/IAmKings/LKanvas/0.16.0-beta02/`），
   Catnip 侧升级 `gradle/libs.versions.toml` 的 `lkanvas = "0.16.0-beta02"` 并按
   §4.3 配置 MACD/VOL 实例样式（单独提交，可整体还原依赖行回滚 beta01）。
3. Central Portal 上传沿用既有 GO 决策流程（手动）。

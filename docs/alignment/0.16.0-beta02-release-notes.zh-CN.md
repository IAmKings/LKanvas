# 0.16.0-beta02 候选修正记录（2026-11-04）

状态：beta02 修正及发布前验收记录。2026-11-05 已获授权合并 main 并推送发布标签；
公开制品是否就绪以 JitPack 解析结果为准，不能仅凭标签存在判定 S5 完成。
固定上游 `third_party/klinechart-v10.1.0`、模块结构和指标公式保持不变。
详细关闭证据见 [修正验收记录](catnip-remediation-fixes-2026-11-04.zh-CN.md)。

## 样式消费

- LINE、BAR 按各自图形类型独立计数，同类型数组循环使用；每个指标实例从第 0 槽开始。
- 上游 Map 的 `bars[i]` 表示第 i 个 BAR 的完整三色槽，绝不是涨/跌/平三个数组位置。
  `IndicatorStyleSpec.bars`、`PolygonStyle` 的末尾三色字段提供类型化写法。
- 接受 `IndicatorStyleSpec`、`IndicatorStyle`、`IndicatorStylePatch`、上游颜色 Map 和
  旧 `List<PolygonStyle>`。旧单色 PolygonStyle 适配为每图形的单色槽。
- 不带动态样式回调的 BAR 使用该槽的 noChangeColor；不擅自按正负分色。
  VOL/MACD 的已有回调继续决定颜色分支，绘制与图例共用解析结果。
- Map 部分样式保留数组位置；缺省颜色不从后续元素移位，也不逐字段混入全局数组。
  Android 无 CSS `currentColor`，此缺省映射为 Canvas 黑色，属于明确的平台适配。
- sample 和 Catnip 同步改用完整三色槽。仅颜色消费已验收，未声明完整上游 styles 支持。

## 格式化与缓存

- 三参 `Formatter.formatDate(ts, template, type)` 保持。模板使用上游 `YYYY` / `MM` /
  `DD` / `HH` / `mm` / `ss`，按 SECOND–YEAR 周期及 xAxis/tooltip 场景选择。
- xAxis、tooltip、语义及 legendData 接入有效 formatter。旧两参 FormatConfig 回调保留。
- formatter、时区和 locale 变化均触发重绘及 tooltip 缓存失效；导出使用同一消费链。
- Catnip 的分钟轴 `DD HH:mm`、日/周/月轴 `MM-DD` 是宿主显示策略，使用显式上海时区；
  不改变库的通用周期契约。

## 兼容性登记

| 项 | 兼容性与边界 |
|---|---|
| ChartTheme | 新字段已移到末尾；旧位置参数源码已编译验证 |
| PaneRenderers | 实际为公开 API；保留旧三参 figureColors 和单参 styleOverrideFor 入口 |
| FormatConfig / ChartTheme / PolygonStyle / PolygonStylePatch | 末尾默认参数保留旧源码调用；data class 构造器、copy 的 JVM 签名变化，**旧预编译调用方需重编译** |

| styles 颜色行为 | 修正旧错误的数组含义；用两元素表达涨/跌的调用方应迁移为一个完整三色元素 |

不承诺 beta01 → beta02 二进制直接替换兼容。现有依赖应随应用源码一起重建。

# LKanvas Logo · Concept Brief

2026-11-01 · 候选过程留档。用户已选定 A「刻度 K」，正式资产见 `final/`。

名称沿用 README 的 **LKanvas**。服务于 Android / Compose 金融图表库，首先出现在 sample 品牌栏、Android 图标与仓库文档。受众为选型、集成和排查问题的开发者。品牌特征：精准、克制、可靠、清楚。

假设：不更名、不使用交易所或券商符号；蓝色只承担品牌角色；先证明黑白和小尺寸可用。候选均为本次绘制的几何 SVG，无字体、外链、位图、滤镜或渐变。

## 词图与类别约束

- LKanvas → K / L / canvas → 骨架、边界、窗口。
- 图表 → 时间、采样、视口 → 间隔、切口、对齐。
- 库 → 可组合、可验证 → 模块、留白、稳定的基准。
- 避免：向上箭头、三根递增柱、牛、金币、盾牌；不能暗示投资收益。

参考库用于观察轮廓和几何构造，未拷贝路径。检查了 Kotlin、Framer、Pagekit 的结构，主动避开实心方形中的 K 切口和 Framer 的三角拼法。

## 概念长名单

评分为设计判断，满分 5；综合清晰度、区别度、简洁度、相关性与小尺寸表现。

| 方向 | 一句话构想 | 类型 | 分数 / 决定 |
|---|---|---|---|
| A · 刻度 K | 竖直基准与留出呼吸缝的折臂，形成可一眼识别的 K | 字母标记 | 4.5 · 推荐绘制 |
| B · 双向画布 | 两个对向直角构成有开放通道的绘图窗口 | 组合字母 / LK 暗示 | 4.1 · 绘制 |

## 三个候选的构造与取舍

**A · 刻度 K：**独立直立笔画 + 45° 折臂，二者不相碰；以明确的 K 识别建立品牌记忆。两部分之间的留白对应图表中“数据与参考”的秩序，不使用箭头造型。适合 Android 图标和导航栏。风险是 K 类字母标记较常见，应通过独立的折臂比例与间隔保留自身特征。

**B · 双向画布：**两段相对的等厚直角，围出对角贯通的空白；更偏向工具、画布与组合能力。轮廓安静，适合 SDK。风险是字母联想弱，也可能被理解为裁切框。

**C · 采样窗口：**开放的厚壁窗口 + 一枚脱离的方块；主轮廓与样本之间有明确间距。适合把应用理解为数据观察工具。风险是与数据看板类别的通用窗口语言接近，需要更长时间建立品牌归属。

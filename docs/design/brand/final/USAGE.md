# LKanvas · 刻度 K 使用说明

2026-11-01 · A 方向已由用户确认。

独立的竖直基准与 45° 折臂构成 K，间隔清楚、轮廓克制。它标识图表工具与绘图能力，不表达收益或投资建议。

## 文件选择

| 场景 | 文件 |
|---|---|
| 深色背景上的主符号 | `lkanvas-symbol-color.svg`，冷蓝 `#79A8FF` |
| 浅色背景上的主符号 | `lkanvas-symbol-mono-255bc8.svg`，深蓝 `#255BC8` |
| 浅色页面 / SDK 文档 | `lkanvas-logo-horizontal.svg`，蓝色符号与墨色字标 |
| 深色页面的彩色组合 | `lkanvas-logo-horizontal-dark.svg`，冷蓝符号与白色字标 |
| 深色页面 | `lkanvas-logo-horizontal-white.svg` |
| 竖向签名 | `lkanvas-logo-stacked.svg` 或 black / white 版本 |
| 单独字标 | `lkanvas-wordmark.svg` |
| 16–24px 窄小场景 | `lkanvas-symbol-small.svg` 或 `lkanvas-symbol-favicon.svg` |
| 应用商店 / 品牌预览 | `lkanvas-app-icon-1024.png` |
| 浏览器标签 | `favicon.ico`（16 / 32 / 48px） |
| Android 启动器 | sample 的 `mipmap-anydpi*/ic_launcher.xml`；不是把 PNG 再切成图标 |

Android 23–25 使用矢量底板；26+ 使用前景和背景分离的 adaptive icon；33+ 提供 monochrome 层。符号居于自适应图标中央安全区，启动器可按系统形状裁切。

## 比例、尺寸与留白

主符号 viewBox 为 256×256。竖笔画宽 36、间隔 24；轮廓左右边界 36 / 220，上下边界 40 / 216。水平组合在符号右侧留出间距，不将字标塞进 K 的空白。

符号外侧至少保留一根竖笔画宽度的空间，字标四周也至少留同等比例空间。独立符号最小建议 16px；水平组合至少 120px 宽，小于此尺寸优先只用符号。UI 品牌栏使用 28–32dp 符号。

反白符号做了轻量笔画减重，字标轮廓保持一致。不要用 CSS 描边伪造反白版，不拉伸、不旋转、不加阴影或渐变、不用行情的绿/红替换品牌色。

## 色彩与字体

| 颜色 | HEX | RGB | 用途 |
|---|---|---|---|
| 冷蓝 | `#79A8FF` | 121 / 168 / 255 | 深色背景主符号 |
| 深蓝 | `#255BC8` | 37 / 91 / 200 | 浅色背景主符号 |
| 墨色 | `#152238` | 21 / 34 / 56 | 浅色背景字标 |
| 石墨 | `#0B1018` | 11 / 16 / 24 | 应用图标底色 |
| 白 | `#FFFFFF` | 255 / 255 / 255 | 深色反白 |

字标为本次构造的几何路径，没有嵌入字体，也不要求安装字体。应用普通文字使用 Android 系统字体；品牌组合的源文件不依赖系统字体渲染。屏幕资产使用 sRGB；本轮未制作印刷专色规范。

## 检查与范围

已做 SVG 静态审计、黑白两轮概念检查、16–64px、镜像/旋转与正负色观察。正式标志与水平字标、应用图标已经渲染查看。`presentation.html` 包含软件场景的 README、应用图标、页面、终端、贴纸与社交展示；这些是标志使用示意，不代表实现了网页或联网服务。

SVG 无位图、外链、滤镜、渐变或活文字。候选与定稿均保留，方便追溯；不包含第三方参考 Logo 的使用授权，也不包含商标近似检索。
